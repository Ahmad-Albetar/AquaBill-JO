# 💧 AquaBill JO — حاسبة فاتورة المياه الأردنية

أداة ويب مجانية ومستقلة (غير حكومية) تساعد الأسر الأردنية على:

- حساب الفاتورة الشهرية المتوقعة بدقة حسب نظام الشرائح التصاعدي الرسمي (مياه + صرف صحي)
- مقارنة كلفة المتر الإضافي من العداد مقابل صهريج المياه المتنقل
- نصائح عملية لتوفير الماء دون الوقوع بمشكلة الانقطاع

مبنية بالكامل بـ **HTML + CSS + JavaScript** فقط، بدون أي إطار عمل (React/Vue/إلخ)، وتدعم العمل كتطبيق ويب تقدمي (**PWA**) يعمل بدون إنترنت بعد أول زيارة.

### ⚙️ ملفات مصدرية مقابل ملفات إنتاج (Source vs. Production)
لكل من CSS وJavaScript نسختان: **مصدرية** (`script.js`, `style.css`, `config.js`) للقراءة والتعديل والتعليقات التوضيحية بالعربية، و**مُصغَّرة** (`.min.`) وهي ما يُحمِّله `index.html` فعلياً بالإنتاج لسرعة تحميل أفضل. **إن عدّلتم أي ملف مصدري، أعيدوا توليد نسخته المُصغَّرة** بهذه الأوامر (تحتاج Node.js مثبتاً محلياً):

```bash
npm install -g terser clean-css-cli
terser config.js --compress --mangle -o config.min.js
terser script.js --compress --mangle -o script.min.js
cleancss -o style.min.css style.css
```

ثم ارفعوا التغييرين معاً (المصدري والمُصغَّر) — النسخة المُصغَّرة فقط هي التي يقرأها المتصفح فعلياً.

## ▶️ التشغيل محلياً

**الطريقة الأبسط:** افتحوا `index.html` مباشرة بنقرتين بأي متصفح (كروم، فايرفوكس، سفاري). الأداة تعمل بالكامل فوراً.

**ملاحظة:** ميزة Service Worker (العمل بدون إنترنت) لا تُفعَّل عند الفتح المباشر من الملفات المحلية (`file://`) في بعض المتصفحات — تحتاج خادماً محلياً بسيطاً أو رفعها على GitHub Pages لتعمل بالكامل. لتشغيل خادم محلي بسيط (اختياري):

```bash
# باستخدام بايثون (متوفر افتراضياً على أغلب الأجهزة)
python3 -m http.server 8000
# ثم افتحوا: http://localhost:8000
```

## 🚀 النشر على GitHub Pages

1. أنشئوا حساباً مجانياً على [github.com](https://github.com) إن لم يكن لديكم واحد
2. أنشئوا مستودعاً (Repository) جديداً باسم `Water-Bill-Calculator` (أو أي اسم تريدونه)
3. ارفعوا **كل الملفات والمجلدات** بنفس الهيكل أعلاه (حافظوا على اسم `index.html` بالضبط، ومجلد `images/` بنفس الاسم)
4. من المستودع: **Settings → Pages**
5. تحت "Build and deployment"، اختاروا المصدر (Source): **Deploy from a branch**
6. اختاروا الفرع `main` والمجلد `/ (root)`، ثم احفظوا
7. خلال دقائق قليلة، سيظهر رابط موقعكم بالشكل:

```
https://<اسم_المستخدم>.github.io/Water-Bill-Calculator/
```

### ✅ رابط الموقع مضبوط فعلياً

ملف `index.html` مضبوط بالفعل على الرابط الحقيقي (وليس نصاً نائباً):

```html
<meta property="og:url" content="https://ahmadalbetar295.github.io/Water-Bill-Calculator/">
```

يظهر هذا الرابط بـ5 مواضع (`canonical`، `og:url`، `og:image`، `twitter:image`، وJSON-LD). **إن غيّرتم اسم المستودع على GitHub مستقبلاً** (مثلاً لغير `Water-Bill-Calculator`)، ابحثوا عن `ahmadalbetar295.github.io/Water-Bill-Calculator` بملف `index.html` وحدّثوه بكل المواضع الخمسة ليطابق الرابط الفعلي الجديد.

بدون هذه الخطوة، الأداة تعمل بشكل طبيعي 100%، لكن معاينة الرابط (الصورة والعنوان) عند مشاركته بواتساب أو فيسبوك قد لا تظهر بشكل صحيح.

## 📱 تثبيت الأداة كتطبيق على الهاتف (PWA)

بعد نشرها على GitHub Pages (يجب أن يكون الموقع عبر HTTPS، وGitHub Pages يوفر هذا تلقائياً):

- **أندرويد (كروم):** عند زيارة الموقع، يظهر إشعار "ثبّتوا الأداة على شاشتكم الرئيسية" تلقائياً بأسفل الشاشة. أو من قائمة المتصفح (⋮) اختاروا "إضافة إلى الشاشة الرئيسية"
- **آيفون (سفاري):** اضغطوا زر المشاركة (المربع مع السهم) ثم "إضافة إلى الشاشة الرئيسية"

بعد التثبيت، تظهر الأداة كأيقونة تطبيق عادي على الهاتف، وتعمل حتى بدون إنترنت.

## 🔧 التحديث مستقبلاً

### تعديل جدول التعرفة
الجدول مقفل افتراضياً من واجهة الموقع لمنع التعديل العرضي. لفتحه، اضغطوا زر "تعديل" أعلى الجدول وأدخلوا الرمز السري الافتراضي: **`2580`**

**لتغيير هذا الرمز:** افتحوا `script.js`، وابحثوا عن السطر:
```js
const EDIT_PIN = "2580";
```
استبدلوا `"2580"` بأي رمز تريدونه، بين علامتي التنصيص.

> **ملاحظة أمان صادقة:** هذا الرمز حماية بسيطة على مستوى الواجهة (client-side) فقط، وليس تشفيراً حقيقياً — أي شخص يفتح "عرض الكود المصدري" بالمتصفح يقدر يراه بسهولة. وهو كافٍ لمنع التعديل العرضي من العائلة أو الزوار، لكن ليس لحماية بيانات حساسة فعلياً. لحماية حقيقية على مستوى الخادم، يمكن استخدام **Cloudflare Access** (مجاني حتى 50 مستخدم) فوق الاستضافة — ابحثوا عن "Cloudflare Access free tier" لتفاصيل الإعداد.

### تحديث أسعار الشرائح عند تغييرها رسمياً
الحكومة الأردنية ترفع تعرفة المياه تدريجياً ضمن خطة إعادة الهيكلة حتى 2028-2029. لتحديث الأرقام بالكود مباشرة (بدل الواجهة)، افتحوا `script.js` وعدّلوا مصفوفة `tiers` بأعلى الملف:

```js
const tiers = [
  { label: "0-6 (مقطوعية)", upTo: 6,        water: 2.50, sewage: 0.23, flat: true },
  { label: "7-12",          upTo: 12,       water: 0.60, sewage: 0.15 },
  // ... عدّلوا الأرقام هنا حسب التعرفة الجديدة
];
```

### تحديث نسخة الـ Service Worker بعد أي تعديل بالملفات
بعد أي تعديل بـ `index.html` أو `style.css` أو `script.js`، افتحوا `service-worker.js` وغيّروا رقم الإصدار حتى يُجبر المتصفح على تحميل النسخة الجديدة بدل القديمة المخزّنة مسبقاً:

```js
const CACHE_NAME = 'aquabill-jo-v6'; // غيّروها إلى v7, v8, إلخ مع كل تحديث، ويجب أن تطابق APP_CONFIG.cacheVersion بـ config.js
```
